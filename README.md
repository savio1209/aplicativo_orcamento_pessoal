# 💰 Controle de Gastos Pessoal

Aplicativo desktop desenvolvido em Python para controle de receitas e despesas pessoais.

## 📌 Sobre o projeto

O aplicativo permite cadastrar receitas, despesas e categorias, visualizar os registros e acompanhar as informações financeiras por meio de gráficos e indicadores.

## 🚀 Funcionalidades

- Cadastro de receitas
- Cadastro de despesas
- Cadastro e exclusão de categorias
- Exclusão de registros
- Visualização das movimentações
- Cálculo de receitas, despesas e saldo
- Gráfico de barras
- Gráfico de pizza por categoria
- Indicador percentual do saldo

## 🛠️ Tecnologias

- Python
- Tkinter
- SQLite
- Matplotlib
- Pillow
- tkcalendar
